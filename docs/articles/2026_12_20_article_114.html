Duas Linhas no Balcão: PDV Desktop em Rust e Tauri 2

Cara Core Informática 20 de dezembro de 2026
Tempo estimado de leitura: ~8 minutos
Ideia central: não estamos “migrando o PDV para Rust”. Estamos abrindo uma segunda linha desktop do mesmo CaraCore PDV — madura em Java, piloto em Rust + Tauri 2 — para quem precisa avaliar outra engenharia no chão da loja, com os mesmos princípios de Bunker e SQLite local.

O que mudou em dezembro de 2026

Em 20 de dezembro de 2026, a Cara Core formaliza no retrô o que já vinha sendo construído na oficina: o Cara Core PDV Desktop (Rust + Tauri 2), release v0.1.1, com instaladores em português do Brasil e publicação verificada em GitHub Releases.

A vitrine comercial continua em rust-pdv.caracore.com.br. O caixa maduro, multiplataforma e consolidado permanece em pdv.caracore.com.br (canal Java v3.1.2-free).

Se você chegou até aqui esperando o texto “por que abandonar Java”, pare agora. Este artigo é sobre por que avaliar Rust e Tauri 2 — e em que cenário essa avaliação faz sentido — sem romper a operação que já funciona.

Dois PDVs Desktop, um produto de negócio

O CaraCore PDV é um só na proposta para PME: caixa offline-first, soberania local, continuidade quando a rede falha, preparação para a transição tributária e rotina de loja previsível. O que se multiplica é a stack de engenharia, não a promessa comercial.

Regra de comunicação: “PDV v3” sozinho confunde. v3.1.x é faixa Java; v0.1.x é faixa Rust. O posicionamento V3 de negócio (PME, PIX Split 2027) é comum às duas linhas.

Por isso falamos em coexistência, não em substituição. A matriz institucional resume a comparação em Como as duas linhas PDV convivem.

Por que Rust no núcleo do caixa

Rust entrou na conversa do PDV por razões de engenharia de sistema, não por moda. No balcão, o custo de um bug em memória ou de uma condição de corrida não é abstrato: é fila, é divergência de caixa, é turno perdido.

  • Segurança de memória em compile time: o compilador impede classes inteiras de erros que, em outras linguagens, só aparecem sob carga ou após meses em produção.
  • Concorrência explícita: o modelo de ownership facilita serviços paralelos (impressão, fila fiscal, sincronização) sem “corrigir no susto” com locks espalhados.
  • Performance previsível: binário nativo enxuto, com menos surpresas de GC em horário de pico no PDV.
  • Contrato de confiabilidade: o núcleo pdv-core em Rust concentra regras de caixa, auditoria, pagamentos e fronteiras de domínio com testes de regressão — a UI não “inventa” regra de negócio.

Isso não significa que Java seja “lento” ou “inseguro”. Significa que a oficina quis uma segunda via de validação com outro compilador, outro runtime e outro perfil de binário — útil para pilotos controlados e para equipes que já dominam ecossistema web + Rust.

Por que Tauri 2 na casca desktop

Se Rust responde “como o motor confia nos dados”, Tauri 2 responde “como a loja vê e instala o produto”. A versão 2 consolidou o que buscávamos para desktop brasileiro:

  • Shell leve: WebView nativa (WebView2 no Windows) em vez de empacotar um navegador inteiro — instalador menor, boot mais rápido.
  • UI em React + TypeScript: reaproveita competência de frontend, design system e testes de interface sem prender o time a uma toolkit desktop legada.
  • Instaladores pt-BR: NSIS para o lojista, MSI pt-BR para TI, ZIP portátil para piloto — mesma linguagem de entrega que o mercado PME já entende.
  • Multiplataforma na mesma oficina: Windows, Linux e macOS na pipeline de release v0.1.1, alinhada ao discurso Bunker (dados locais, operação no seu ambiente).
  • Fronteira clara: comandos IPC entre UI e núcleo Rust — a interface pede; o core decide e persiste em SQLite.
Analogia de oficina: Tauri é a fachada e o balcão de atendimento; Rust é a cofre e o livro-caixa. O cliente vê fluidez; o auditor vê trilha.

Comparação honesta: Java (maduro) × Rust + Tauri (piloto)

A tabela abaixo não elege “vencedor”. Ela orienta qual linha abrir primeiro na sua loja ou na sua equipe de TI.

Quando avaliar Rust + Tauri: piloto em Windows com MSI pt-BR, equipe que quer UI React com núcleo Rust, ou laboratório de performance e empacotamento antes de escalar.

O que “migrar” não significa aqui

Migração, no discurso de nuvem, costuma ser “desligar A, ligar B na mesma noite”. No PDV Cara Core, a segunda linha existe para aprender sem quebrar o caixa que paga as contas.

  • Não há obrigação de trocar o PDV Java por Rust.
  • Não há promessa de “reescrever tudo” para marketing.
  • Há oficina dedicada (caracore-pdv-rust), loja dedicada (rust-pdv) e releases assinadas com SHA256.
  • Há licença CaraCore Seed opcional na linha Rust — degradação graciosa quando a chave não está ativa, sem prender a operação básica do piloto.

Se a sua pergunta é “devo migrar?”, reformule: “devo pilotar a linha Rust em um terminal paralelo, com rollback simples e o Java intacto?” Para a maioria das PMEs em dezembro de 2026, a resposta ainda começa em não substituir — começa em medir.

Bunker, SQLite e a mesma filosofia

As duas linhas compartilham o que o retrô já defendeu no artigo do apagão: o modem pode cair; o caixa não deveria. SQLite local, fila de operações, fechamento de turno e auditoria não são exclusividade de uma linguagem — são compromisso de produto.

Rust + Tauri não vendem “nuvem mágica”. Vendem outro caminho para chegar ao mesmo compromisso, com binário enxuto e pipeline de release que a oficina controla — build, manifesto, smoke, publicação.

Como experimentar com segurança

  1. Baixe a release v0.1.1 pelos releases oficiais e confira o checksum.
  2. Leia os formatos (NSIS, MSI, ZIP) na página Formatos da loja Rust.
  3. Instale em um terminal de teste — não no único caixa da loja na véspera de Natal.
  4. Compare tempo de abertura, fluxo de venda, impressão e fechamento com o PDV Java que você já confia.
  5. Envie feedback para suporte@caracore.com.br com versão, SO e cenário — piloto assistido é parte do desenho.

Conclusão

A iniciativa Rust + Tauri 2 no PDV Desktop não é fuga do Java — é engenharia paralela com honestidade comercial. Rust entra pelo contrato de confiabilidade do núcleo; Tauri 2 entra pela casca instalável e pela UI que o time consegue evoluir rápido.

Em 2026, a pergunta certa não é “qual stack vence?”. É “qual stack resolve o seu chão hoje — e qual você pode pilotar amanhã sem apostar o faturamento?”. Duas linhas no balcão. Um Bunker. Escolha informada.
