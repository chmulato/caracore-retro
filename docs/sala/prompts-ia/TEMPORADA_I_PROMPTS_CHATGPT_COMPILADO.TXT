================================================================================
NOTAS FINAIS PARA O GERADOR DE IMAGENS
================================================================================

1. Consistência visual:
   - Manter paleta azul-âmbar em todos os episódios
   - Filme simulado (grain, vignette sutil)
   - Sem UI design patterns quadrados/liso demais
   - Tudo "real", fotografado, não cartoon

2. Elemento "03/03":
   - Cada episódio DEVE ter uma referência discreta ao "03/03"
   - Pode ser: carimbo, selo, etiqueta, reflexo, elemento de fundo
   - Não deve ser óbvio; deve parecer "encontrável"

3. Elemento jovem (infanto-juvenil):
   - Ep 1-7 TODOS os episódios devem incluir uma presença jovem secundária
   - Pode ser observador, aprendiz, reflexo, silhueta
   - Crescimento narrativo: observador → coordenador → líder (futuro)

4. Qualidade gerador:
   - Se DALL-E: usar "style raw" ou "style photorealistic"
   - Se Midjourney: usar "--q 2" (qualidade alta) e "--style raw"
   - Se ChatGPT Vision: descrever detalhes; deixar gerar

5. Ordem de uso:
   - Começar com os 9 episódios individuais (ordem: 1, 2, 3, 4, 5, 6, 7, 8, 9)
   - Depois gerar a imagem hero (mosaico 3x3 completo)
   - Depois gerar variantes (ângulos diferentes, se necessário para rede social)
