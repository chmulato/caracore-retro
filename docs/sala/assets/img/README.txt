Imagens das campanhas (PNG, JPG) — Sala de Notícias
====================================================

Pasta para salvar imagens geradas por IA (DALL·E, Midjourney, Ideogram, etc.)
e outras artes das campanhas Facebook, Instagram e LinkedIn.

Formato do nome dos arquivos:
  Facebook:   YYYY_MM_DD_artefato_(01)_(01).png  | HTML _(01)_F.html (sala/facebook/)
  Instagram:  YYYY_MM_DD_artefato_(01)_(01).png  | HTML _(01)_G.html (sala/instagram/). Sequência 01; sufixo G.
  LinkedIn:   YYYY_MM_DD_article_(87)_(01).png   | HTML _(87)_L.html (sala/linkedin/). Article a partir de 87.
  Outras:     YYYY_MM_DD_nome.png

Exemplos:
  2026_03_15_soberania_mar_(01)_(01).png   (Facebook)
  2026_03_04_soberania_mar_(01)_(01).png   (Instagram)
  2026_03_09_soberania_(87)_(01).png      (LinkedIn, article 87)

Estratégia completa: sala/prompts-ia/ESTRATEGIA_COPIAR_SALVAR.txt
