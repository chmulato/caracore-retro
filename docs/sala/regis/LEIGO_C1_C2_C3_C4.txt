PASSO A PASSO COM DESENHOS (PASSOS 1–4) — Formato para leigos
================================================================================
Cara Core Informática · Sala de Notícias · regis
Instruções com informação completa. Cada passo tem um desenho (Passo 1, 2, 3, 4).
No projeto, C1–C4 designam o modelo C4 de arquitetura (Contexto, Contêineres,
Componentes, Código). Ver C4_MODELO.txt ou C4_MODELO.html.
No final do trabalho, rode o script Python para validar se tudo foi executado.

ONDE ESTÁ CADA REDE (AUTOMAÇÃO)
  Facebook (F):   face/   — artefatos em face/artefatos/
  Instagram (G):  gram/   — artefatos em gram/artefatos/
  LinkedIn (retro, depois do 86): retro/ — articles em retro/articles/

--------------------------------------------------------------------------------
PASSO 1 — Abrir o artefato e copiar o texto
--------------------------------------------------------------------------------
  [Passo 1] Desenho: abrir a página HTML do artefato (Face, Gram ou Retro),
       selecionar o texto do post e usar Ctrl+C para copiar.

  Abra a página HTML do artefato da rede que você está trabalhando
  (Facebook = face, Instagram = gram, LinkedIn = retro). Selecione todo o texto
  do post com o mouse (ou triplo clique). Aperte Ctrl+C para copiar. Esse texto
  foi escrito pela Lia; você só copia e cola na rede.

--------------------------------------------------------------------------------
PASSO 2 — Colar o texto na rede e copiar o prompt da caixa
--------------------------------------------------------------------------------
  [Passo 2] Desenho: na rede (Facebook, Instagram ou LinkedIn), colar o texto com
       Ctrl+V; na mesma página do artefato, localizar a caixa "Texto para colar
       na IA" e copiar o conteúdo com Ctrl+C.

  Na rede social, clique no campo onde se escreve o post. Aperte Ctrl+V para
  colar o texto. Volte à página do artefato. Procure a caixa com o título
  "Texto para colar na IA". Selecione o texto dentro dessa caixa e aperte
  Ctrl+C para copiar o prompt (é esse texto que você cola na ferramenta de IA
  que gera imagens).

--------------------------------------------------------------------------------
PASSO 3 — Gerar a imagem na IA e salvar com o nome correto
--------------------------------------------------------------------------------
  [Passo 3] Desenho: abrir o site/app de IA de imagens, colar o prompt (Ctrl+V),
       gerar a imagem; ao salvar, escolher a pasta sala/assets/img/ e o nome no
       formato YYYY_MM_DD_artefato_(01)_(01).png (ou article_(87)_(01).png
       para LinkedIn).

  Abra o site ou o app que gera imagem por IA. Cole o prompt (Ctrl+V). Gere a
  imagem. Ao salvar:
    · Pasta: sala/assets/img/
    · Nome: Facebook   = YYYY_MM_DD_artefato_(01)_(01).png e _(01)_F.html
            Instagram = YYYY_MM_DD_artefato_(01)_(01).png e _(01)_G.html
            LinkedIn  = YYYY_MM_DD_article_(87)_(01).png e _(87)_L.html (87+)
  Detalhes: prompts-ia/ESTRATEGIA_COPIAR_SALVAR.txt

--------------------------------------------------------------------------------
PASSO 4 — Validar o trabalho com o script Python
--------------------------------------------------------------------------------
  [Passo 4] Desenho: ao terminar a sessão, abrir o terminal na pasta do repositório,
       rodar o Python (versão baseline do Windows Store) e executar
       scripts/validar_sala.py; conferir se apareceu validação OK ou corrigir
       o que o script indicar.

  1. Use o Python baseline (versão correta instalada pela Windows Store).
  2. Abra o terminal na pasta do repositório da Sala.
  3. Execute: python scripts/validar_sala.py  (ou py scripts/validar_sala.py)
  4. O script verifica face (F), gram (G) e retro (LinkedIn depois do 86).
     Se algo estiver fora do padrão, ele indica o que corrigir.

================================================================================
RESUMO
  Material sempre em HTML. Em cada página há uma caixa "Texto para colar na IA"
  e instruções passo a passo para salvar no formato correto. Assets por rede

  Automação: face (F), gram (G), retro (LinkedIn depois do 86).
