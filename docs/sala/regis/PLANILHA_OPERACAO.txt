================================================================================
PLANILHA DE OPERAÇÃO — Transparência total
================================================================================
Cara Core Informática · Sala de Notícias · regis
A planilha é o coração da confiança. Se o robô não registrar, o trabalho não existiu.
================================================================================

ARQUIVO
  sala/planilha_sala.csv (delimitador: ;, encoding UTF-8)

COLUNAS (nome no CSV → significado para o jovem)
  data              → Data da sessão (YYYY-MM-DD)
  tarefa_do_dia     → Descrição da tarefa / o que está planejado
  trabalho_feito    → Status / trabalho feito (resumo do que você executou)
  horas_previstas  → Meta de horas para o dia
  horas_trabalhadas → Horas (tempo real que você trabalhou)
  valor_sessao_cc   → Valor CC (pagamento desta sessão em dinheiro CC)
  acumulado_cc      → Acumulado (total em dinheiro CC até aqui)
  inicio_sessao     → Início (data e hora em que você começou)
  fim_sessao        → Fim (data e hora em que você encerrou)

EQUIVALÊNCIA COM NOMES AMIGÁVEIS
  ID Tarefa / linha: cada linha da planilha é uma sessão (data + início).
  Descrição da Tarefa  = tarefa_do_dia
  Status / Trabalho Feito = trabalho_feito
  Início  = inicio_sessao
  Fim     = fim_sessao
  Horas   = horas_trabalhadas
  Valor CC = valor_sessao_cc
  Acumulado = acumulado_cc

QUEM ATUALIZA
  Robô 01 (iniciar_trabalho): preenche data, tarefa_do_dia, horas_previstas,
  acumulado_cc (até a sessão anterior), inicio_sessao.
  Robô 02 (validar_trabalho_executado): preenche trabalho_feito,
  horas_trabalhadas, valor_sessao_cc, acumulado_cc, fim_sessao.

  Você não precisa editar a planilha à mão. Os robôs fazem isso de forma
  transparente.
