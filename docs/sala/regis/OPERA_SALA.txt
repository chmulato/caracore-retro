================================================================================
Cara Core Informática · Sala de Notícias · regis
Carga: ~3 horas por semana. Ambiente: saudável e silencioso.
Esta sala é pública e transparente. Você não precisa criar nada do zero:
só copiar, colar e salvar com o nome certo.
Premissa: o diferencial competitivo está no valor da execução; a recompensa
é proporcional à entrega validada. Ver regis/TEXTO_RECEPCAO.txt e
regis/ESTRATEGIA_EXECUCAO.txt.

GUIA PARA O JOVEM (16+): regis/GUIA_EXECUCAO_JOVEM.txt — bem-vindo, seu papel,
as 4 regras e linguagem simples. Os 6 robôs: regis/OS_6_ROBOS.txt.

QUEM ESCREVE
  A Lia é a nossa redatora. Todo o texto que você copia e cola nas redes foi
  pensado por ela — tom, mensagem, estratégia. Referência: regis/LIA_CORELLI_VOZ.txt.

ONDE ESTÁ TUDO
  No site da Cara Core Informática (matriz) estão todos os insumos para o
  discurso e a propaganda do nosso negócio. O site diz tudo. O marketing é
  destrinchar com o pensamento da Lia: pegar o que está no site e nas
  diretrizes da Sala e levar para cada rede no jeito certo.

O QUE VOCÊ FAZ (SÓ TRÊS COISAS)
  1. TEXTO: Abra o artefato ou artigo (Face, Gram ou Retro). Selecione o texto,
     Ctrl+C. Na rede (Facebook, Instagram ou LinkedIn), Ctrl+V.
  2. IMAGEM: Copie o texto da caixa de prompt (Ctrl+C). Abra a ferramenta de IA
     que gera imagem, cole (Ctrl+V), gere. Salve com o NOME CORRETO do
     artigo/artefato para encaixar na estratégia. Pasta: sala/assets/img/
  3. NOME DO ARQUIVO: Use a convenção. Ex.: 2026_03_15_artefato_(01)_(01).png
     (imagem); 2026_03_15_artefato_(01)_F.html (página Facebook). Detalhes:
     prompts-ia/ESTRATEGIA_COPIAR_SALVAR.txt

ONDE PUBLICAR POR REDE
  Facebook  → material em face/ (artefato _F). Plano: sala/facebook/facebook.html
  Instagram → material em gram/ (artefato _G). Plano: sala/instagram/instagram.html
  LinkedIn  → material em https://retro.caracore.com.br/ (articles).  Plano: sala/linkedin/linkedin.html

NOMES QUE ENCAIXAM
  Facebook:  imagem _(01)_(01).png   página _(01)_F.html
  Instagram: imagem _(01)_(01).png   página _(01)_G.html
  LinkedIn:  imagem _(87)_(01).png  página _(87)_L.html
  Sempre com data no início: YYYY_MM_DD.
  Lista completa: prompts-ia/ESTRATEGIA_COPIAR_SALVAR.txt

PASSO A PASSO COM DESENHOS (PASSOS 1–4)
  Instruções para leigos: LEIGO_C1_C2_C3_C4.html e regis/LEIGO_C1_C2_C3_C4.txt.
  Cada passo tem um desenho (Passo 1, 2, 3, 4). C1–C4 = modelo C4 de
  arquitetura (Contexto, Contêineres, Componentes, Código); ver C4_MODELO.

MATERIAL EM HTML
  Em cada página de artefato há uma caixa "Texto para colar na IA" (prompt para
  gerar imagem) e as instruções passo a passo abaixo para salvar os artefatos
  no formato correto. Assets por rede: um para cada (LinkedIn, Instagram,
  Facebook) dentro do que planejamos.

VALIDAÇÃO NO FINAL
  Script único em Python (baseline — versão correta do Windows Store) roda no
  final para validar se o trabalho foi executado com sucesso:
    python scripts/validar_sala.py   (ou py scripts/validar_sala.py)
  O script verifica face (F), gram (G) e retro (LinkedIn depois do 86).
  Repositório: LEIA_PRIMEIRO_REPOSITORIO.txt
