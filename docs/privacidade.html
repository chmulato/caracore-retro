Política de Privacidade

Transparência sobre dados no blog Artigos Retrô.

1. Visão geral

O Artigos Retrô (retro.caracore.com.br) é o blog técnico da Cara Core Informática. É um site 100% estático: publicamos artigos e o seu navegador os lê. Não há cadastro, login de leitores ou área restrita. Esta página descreve, em linguagem direta, o que acontece com os dados de quem visita o site.

2. O que não coletamos

O blog não possui formulários, comentários, boletim por e-mail, painel de analytics ou cookies de rastreamento. Nenhum dado pessoal de visitantes é coletado, armazenado ou compartilhado pela Cara Core neste site.

3. Hospedagem e logs de acesso

O site é hospedado no GitHub Pages. Como qualquer provedor de hospedagem, o GitHub registra logs técnicos de acesso (endereço IP, navegador e data/hora) para operação e segurança do serviço, conforme a Política de Privacidade do GitHub. A Cara Core não acessa nem processa esses logs.

4. Integração com o LinkedIn

Mantemos um aplicativo no portal de desenvolvedores do LinkedIn («Artigos Retrô Cara Core Informática») com um único propósito: publicar automaticamente, no perfil LinkedIn do autor, um anúncio de cada artigo novo do blog. A integração funciona assim:

  • O acesso OAuth é autorizado uma única vez pelo próprio autor da conta. Nenhum visitante do blog usa ou vê esse login.
  • Os escopos utilizados são openid e profile (identificação do autor) e w_member_social (publicação de posts).
  • O token de acesso fica guardado como secret criptografado no GitHub Actions e nunca aparece no site nem no código público.
  • Tokens de membro expiram em 60 dias e são renovados pelo autor com reautorização explícita.
  • Nenhum dado de visitantes do blog é lido, recebido ou transmitido ao LinkedIn por essa integração.

5. Feed RSS e links externos

O feed RSS (feed.xml) é público e não exige nenhum dado para uso. Artigos podem conter links para sites de terceiros; ao clicar neles, você passa a ser regido pelas políticas desses sites, sobre as quais não temos controle.

6. Seus direitos (LGPD)

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) garante a você, a qualquer momento, confirmação, acesso, correção ou eliminação de dados pessoais. Como não coletamos dados de visitantes, na prática não existe registro seu guardado por nós — mas se tiver qualquer dúvida sobre esta política, escreva para suporte@caracore.com.br.

7. Alterações desta política

Se a forma de operação do blog mudar (novas integrações, novos fornecedores), esta página será atualizada antes da mudança entrar em vigor. Última revisão: 10 de novembro de 2026.
