Cara Core Informática · Instruções para quem opera (ex.: jovem 16 anos, 3h/semana). O Seed e o MKT são da Cara Core; não vendemos.

Premissa: A sala é pública e transparente. O diferencial competitivo está no valor da execução; a recompensa é proporcional à entrega validada. Ver regis/TEXTO_RECEPCAO, regis/ESTRATEGIA_EXECUCAO, regis/GUIA_EXECUCAO_JOVEM e regis/ARQUITETURA_SALA_C4.

Cenário canónico: a sala está em tools.caracore.com.br/sala/. Estrutura completa: Estrutura da sala. A entrada pública da matriz em caracore-site/sala redireciona para https://tools.caracore.com.br/sala/.

1. CONTEÚDO DESTE REPOSITÓRIO (sala)

  • Instruções em formato para leigos, com desenhos (Passos 1–4) — LEIGO_C1_C2_C3_C4.html. C1–C4 = modelo C4 (Contexto, Contêineres, Componentes, Código); ver C4_MODELO.html.
  • Material sempre em HTML; em cada página de artefato há caixa "Texto para colar na IA" e instruções para salvar no formato correto.
  • Assets por rede: sala/assets/, face/, gram/, retro/.
  • Script Python no final para validar se o trabalho foi executado com sucesso.

2. PYTHON — VERSÃO CORRETA (BASELINE)

Use a versão correta do Python instalada pela Microsoft Store (baseline). Oficina: repositório caracore-mkt (py -3 scripts\validar_sala.py etc.). Ou, na sala canónica, rode python scripts/sala/validar_sala.py a partir da raiz do repositório.

3. AUTOMAÇÃO — ONDE CADA REDE ENCAIXA

  • Facebook (F): face/
  • Instagram (G): gram/
  • LinkedIn (retro, legado 11-86): sources/sala/redes/retro — referência pública no portal manual LinkedIn da Sala (tools.caracore.com.br).

Tudo precisa encaixar: artefatos _F em face/artefatos/, _G em gram/artefatos/, e a campanha LinkedIn atual em sala/linkedin/. A fila e o calendário públicos estão no domínio tools.caracore.com.br (Sala de Operações).

4. VALIDAÇÃO NO FINAL DO TRABALHO

  1. Salve todos os arquivos (texto, imagens em sala/assets/img/ com nome correto, HTML nos lugares certos).
  2. Rode a oficina: py -3 scripts\validar_sala.py ou py -3 scripts\validar_trabalho_executado.py (repositório caracore-mkt).
  3. Ou na raiz da sala canónica: python scripts/sala/validar_sala.py.
  4. Se aparecer "Validação OK", o trabalho foi executado com sucesso.
