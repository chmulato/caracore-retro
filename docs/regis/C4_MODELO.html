Modelo C4 — C1, C2, C3, C4 (Arquitetura)

C1, C2, C3, C4 = modelo C4 de documentação. Para o fluxo do dia usamos Passos 1–4: Passo a passo · Caixa de ferramentas.

C1: Contexto (System Context)

Visão mais ampla. Como o sistema interage com o mundo exterior. Foco: usuários e sistemas que se comunicam com o software. Público: todos.

C2: Contêineres (Containers)

Primeiro zoom. Contêiner = algo que precisa estar rodando. Foco: aplicações web, bancos de dados, APIs. Público: desenvolvedores e operações.

C3: Componentes (Components)

Decomposição de um contêiner. Foco: agrupamentos lógicos (ex.: Controlador de Pagamentos). Público: arquitetos e desenvolvedores.

C4: Código (Code)

Nível máximo de detalhe. Diagramas de classes ou entidade-relacionamento. Foco: implementação. Muitas equipes geram automaticamente.

Resumo: C1 = Contexto · C2 = Contêineres · C3 = Componentes · C4 = Código. Este documento (resumo C4 na Sala)
