Passo a passo com desenhos (Passos 1–4)

Instruções para leigos (jovens a partir de 16 anos, ensino médio). Cada passo tem um desenho para você seguir com clareza. C1–C4 = modelo C4 de arquitetura; veja C4_MODELO.html. A caixa de ferramentas tem 6 scripts; ver CAIXA_FERRAMENTAS_6_SCRIPTS.html.

Onde está cada rede (automação)

  • Facebook (F): face — artefatos em face/artefatos/
  • Instagram (G): gram — artefatos em gram/artefatos/
  • LinkedIn (retro): sources/sala/redes/retro — referência pública no portal https://tools.caracore.com.br/sala/linkedin/linkedin.html

Passo 1 — Abrir o artefato e copiar o texto

[Passo 1] — Abrir a página HTML do artefato, selecionar o texto do post e usar Ctrl+C para copiar.

Abra a página do artefato da rede que você está trabalhando. Selecione o texto do post. Aperte Ctrl+C para copiar.

Passo 2 — Colar o texto na rede e copiar o prompt da caixa

[Passo 2] — Na rede, colar o texto (Ctrl+V); na página do artefato, localizar a caixa "Texto para colar na IA" e copiar com Ctrl+C.

Na rede social, cole o texto com Ctrl+V. Volte à página do artefato, localize a caixa Texto para colar na IA, selecione o conteúdo e aperte Ctrl+C.

Passo 3 — Gerar a imagem na IA e salvar com o nome correto

[Passo 3] — Abrir o site/app de IA, colar o prompt (Ctrl+V), gerar a imagem; salvar na pasta sala/assets/img/ com o nome no formato indicado.

Abra a ferramenta de IA (DALL·E, Midjourney, Ideogram, etc.). Cole o prompt (Ctrl+V). Gere a imagem. Ao salvar:

  • Pasta: sala/assets/img/
  • Nome: Facebook: YYYY_MM_DD_artefato_(01)_(01).png; Instagram: idem; LinkedIn: YYYY_MM_DD_article_(87)_(01).png. Estratégia copiar/salvar.

Passo 4 — Validar o trabalho com o script Python

[Passo 4] — Ao terminar, abrir o terminal na pasta do repositório, executar validar_sala.py; conferir "validação OK" ou corrigir o que o script indicar.

Rode o script de validação. Execute: python scripts/sala/validar_sala.py (ou py scripts/sala/validar_sala.py). O script verifica se tudo está no lugar e com o nome certo.

Resumo

Material em HTML. Em cada artefato há a caixa Texto para colar na IA. O script Python no final valida tudo.
