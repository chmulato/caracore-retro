Caixa de ferramentas — 6 scripts (robôs)

Os 6 robôs protegem o seu tempo: auditam, transportam e validam. Texto de recepção · Guia (4 regras) · Os 6 robôs.

Os 6 robôs (scripts)

NºRobôScriptO que faz
01O Anfitriãoiniciar_trabalho.pyAbre a sala, apresenta trabalho do dia. Atualiza a planilha (início).
02O Auditor de Entregavalidar_trabalho_executado.pyValida o trabalho; atualiza trabalho feito, horas, valor e acumulado CC.
03O Transportadortransportar_para_salas.pyDistribui artefatos de sala/entrega/ para face, gram e retro.
04Validador Retrovalidar_entrega_retro.pyCheca se o post está ativo no canal Retro (LinkedIn).
05Validador Gramvalidar_entrega_gram.pyCheca se o post está ativo no Instagram.
06Validador Facevalidar_entrega_face.pyCheca se o post está ativo no Facebook.

Planilha da sala de operação

Arquivo: sala/planilha_sala.csv. Colunas: data, tarefa_do_dia, trabalho_feito, horas_previstas, horas_trabalhadas, valor_sessao_cc, acumulado_cc, inicio_sessao, fim_sessao. Detalhes: Planilha de operação.

Fluxo do dia (Passos 1–4)

Passo 1: rodar Script 1 (iniciar). Passo 2: ao terminar, rodar Script 2 (validar e encerrar). Passo 3: Script 3 (transportar). Passo 4: Scripts 4, 5, 6 (validar entrega). Erros mostram mensagem amigável e texto para copiar e enviar.

Como rodar os scripts

Python baseline. Terminal na raiz do repositório. Exemplos:

  • python scripts/sala/iniciar_trabalho.py
  • python scripts/sala/validar_trabalho_executado.py
  • python scripts/sala/transportar_para_salas.py
  • python scripts/sala/validar_entrega_face.py · validar_entrega_gram.py · validar_entrega_retro.py
